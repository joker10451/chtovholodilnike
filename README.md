# Что в холодильнике

Семейное веб-приложение (PWA) для iPhone. Хранит продукты со сроками годности, подбирает рецепты из того, что есть дома, распознаёт фото полок и чеков нейросетью, придумывает и переводит рецепты.

Концепция и дизайн — [docs/concept.html](docs/concept.html).

## Что умеет

- **Холодильник**: продукты со сроками, наклейки свежести, фильтр по месту хранения, «открыл упаковку» пересчитывает срок.
- **Добавление**: штрихкод (живое чтение камерой, EAN и «Честный знак»), фото упаковки, фото полок и чека, диктовка. Товар, прочитанный однажды, запоминается в семейной базе.
- **Рецепты**: подбор по полкам «Спасти продукты», «Всё есть», «Докупить 1–2», замены ингредиентов, оценки семьи, «Любимые» и «Мои».
- **Свои рецепты**: фото из тетради или книги, ссылка, текст из заметок; «Поправить рецепт» обычными словами («на 4 порции, без лука»).
- **Рацион на неделю**: дни готовки впрок с обедом из остатков, истекающие продукты — в блюда до конца срока, хвосты купленных упаковок идут в следующие блюда, нелюбимые блюда не предлагаются.
- **Покупки**: собираются из рациона и рецептов, округляются до упаковок, отделы магазина, «Куплено → в холодильник».
- **Режим готовки**: крупные шаги, таймеры, экран не гаснет; после готовки — списание продуктов, остатки и оценка блюда.
- **Уведомления**: утром — что истекает сегодня и завтра. Вход по почте не нужен.
- **Шеф**: придумывает блюдо из того, что есть; импортирует рецепт по ссылке, из текста или фото страницы книги.
- **Каталог**: ~600 блюд TheMealDB на английском, нейросеть переводит и пересчитывает меры в граммы.
- **Офлайн**: всё, кроме нейросети, каталога, уведомлений и облачной копии, работает без интернета.
- **Итоги месяца**: что готовили, сколько продуктов спасли и что выбросили — с подсказкой, что брать меньше.
- **Резервная копия**: сама раз в день в облако (зашифрована кодом доступа, восстанавливается на новом телефоне) и в файл.

## 1. Запуск на компьютере

Нужен Node.js 20+.

```bash
npm install
```

Скопируйте `.env.example` в `.env.local` и заполните сами:

- `GEMINI_API_KEY` — ключ из [Google AI Studio](https://aistudio.google.com/apikey) (нужен VPN из России);
- `APP_ACCESS_CODE` — придумайте любой код, потом введите его в приложении: **Настройки → Нейросеть**.

> Если ключ где-то засветился (например, был отправлен в чат), выпустите в AI Studio новый, а старый удалите.

```bash
npm run dev
```

Откройте http://localhost:5173. Чтобы открыть на iPhone в той же Wi‑Fi сети, используйте адрес `Network:` из консоли (камера и установка на экран «Домой» там ограничены — полноценно проверяйте после деплоя).

```bash
npm test
```

## 2. Публикация на Vercel

1. Создайте репозиторий на GitHub и отправьте туда проект.
2. На [vercel.com](https://vercel.com) → **Add New → Project** → выберите репозиторий. Настройки сборки подтянутся из `vercel.json`.
3. В **Settings → Environment Variables** добавьте `GEMINI_API_KEY` и `APP_ACCESS_CODE`.
4. **Deploy**. Адрес будет вида `https://имя-проекта.vercel.app`.

Серверная функция `api/ai.ts` без `APP_ACCESS_CODE` на Vercel не запустится — это защита вашего бесплатного лимита от чужих.

## 3. Уведомления, облачная копия и журнал ошибок (необязательно)

Вход по почте не нужен, доступ защищён кодом доступа. Здесь же хранятся журнал ошибок с телефона (без продуктов и личных данных, 90 дней) и счётчики лимита нейросети — 60 запросов в час и 300 в сутки, меняются переменными `AI_HOURLY_LIMIT` и `AI_DAILY_LIMIT`. Для уведомлений телефон отправляет на сервер названия продуктов и их сроки; облачная копия шифруется на телефоне кодом доступа — сервер её прочитать не может.

1. Создайте проект на [supabase.com](https://supabase.com) (Free) и выполните в **SQL Editor** [supabase/server.sql](supabase/server.sql).
2. Создайте ключи для уведомлений:
   ```bash
   npx web-push generate-vapid-keys
   ```
3. На Vercel в **Environment Variables** добавьте: `SUPABASE_URL` (адрес проекта Supabase), `SUPABASE_SERVICE_ROLE_KEY` (Supabase → Project Settings → API Keys → service_role), `VITE_VAPID_PUBLIC_KEY` (Public Key), `VAPID_PRIVATE_KEY` (Private Key), `VAPID_SUBJECT` (`mailto:` вашей почты) и `CRON_SECRET` (любая длинная случайная строка). Передеплойте.
4. На телефоне, открытом с экрана «Домой»: введите код доступа, затем **Настройки → Уведомления → Включить**. Облачная копия включится сама.

Облачная копия работает и без ключей уведомлений — достаточно шагов 1 и `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` из шага 3. Хранятся последние 5 копий. Если поменять код доступа, старые копии открываются только старым кодом.

Рассылка идёт раз в день около 9:00 по Москве (расписание — `crons` в `vercel.json`). Если истекать нечему, уведомление не приходит.

## 4. Установка на iPhone

1. Откройте адрес приложения **в Safari**.
2. **Поделиться → На экран «Домой»**.
3. Запускайте с иконки: так приложение работает на весь экран и без интернета.
4. В **Настройках** введите код доступа к нейросети.

## Нейросеть: Gemini или Claude

По умолчанию — Gemini (`AI_PROVIDER=gemini`, модель `gemini-3.5-flash`, можно сменить через `GEMINI_MODEL`).

Переключиться на Claude: `AI_PROVIDER=claude` и `ANTHROPIC_API_KEY`. Модель по умолчанию — `claude-opus-5` (сменить — `CLAUDE_MODEL`); включён серверный запасной вариант на случай отказа модели (`fallbacks: "default"`). Claude платный.

## Устройство проекта

```
api/ai.ts                 функция Vercel → server/ai.ts
api/push.ts, api/cron/    подписка на уведомления и утренняя рассылка
api/backup.ts             облачные резервные копии
api/log.ts                журнал ошибок с телефона
server/                   подсказки для нейросети, Gemini/Claude, импорт по ссылке
src/shared/               общее для сервера и клиента: справочник продуктов, рецепты, сроки, единицы, схемы ответов
src/data/                 IndexedDB (Dexie), очередь сканов
src/lib/                  подбор рецептов, списание, разбор фраз, TheMealDB, фото
src/screens/              экраны приложения
supabase/server.sql       таблицы для уведомлений, копий, журнала ошибок и лимитов
docs/concept.html         концепция и дизайн
```
